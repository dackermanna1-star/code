# TNT Gun (Fabric 1.21.11)

Right-click to shoot primed TNT where you're looking.

- Survival: uses 1 TNT from your inventory per shot. Creative: free.
- Fuse: 1.5 seconds. Cooldown: 0.5 seconds.
- Creative tab: Combat.

Recipe (crafting table):

```
Iron  Iron  TNT
      Flint Iron
            Iron
```
(Flint = Flint and Steel)

Install: put `download/tntgun-1.0.0.jar` and Fabric API into `.minecraft/mods`.

Build yourself: `./gradlew build` (output in `build/libs/`).
