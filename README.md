# Counter-Strike 1.6 — de_dust2 (browser recreation)

A from-scratch recreation of **Counter-Strike 1.6 on de_dust2, circa 2003**, running in
the browser with three.js. The goal is the original look and feel — GoldSrc-style
rendering, baked lightmaps, low-poly models, the 1.6 HUD and menus, CS movement and
weapon handling, round-based bomb defusal against bots — not a modern remake.

No Valve assets are shipped. Every texture, sound, model and the map itself are
generated by code in this repository (see *How it's made* below).

## Running it

```bash
npm install
npm run dev        # http://localhost:5173
# or a production build
npm run build && npm run preview
# or one self-contained HTML file that runs straight from disk (dist/cs16.html)
npm run build && node tools/singlefile.mjs
```

Click the game to capture the mouse. `Esc` opens the main menu.

### Original maps (cs_mansion)

Original GoldSrc maps use your own game files, which are never committed to this
repo. To bundle one into your local build so it's ready in New Game:

```bash
# map .bsp, the folder with its WADs (Half-Life/valve), and optionally the sky folder (valve/gfx/env)
node tools/packmap.mjs path/to/cs_mansion.bsp path/to/Half-Life/valve path/to/Half-Life/valve/gfx/env
npm run build
```

This copies the .bsp, packs just the textures it uses into one small WAD and copies
its skybox into `public/gamedata/` (git-ignored). Otherwise the New Game menu lets you
add the files in the browser.

## Controls (CS 1.6 defaults)

| Key | Action | Key | Action |
| --- | --- | --- | --- |
| W A S D | move | Mouse 1 / 2 | fire / secondary (zoom, silencer, burst) |
| Space | jump | Ctrl | duck |
| Shift | walk (silent) | R | reload |
| E | use (defuse) | G | drop weapon |
| 1–5 | weapon slots | Q | last weapon |
| B | buy menu | M | change team |
| `,` `.` | buy primary / secondary ammo | Tab | scoreboard |
| Z X C | radio menus | Y / U | chat / team chat |
| `` ` `` | console | Mouse wheel | next / previous weapon |
| T | shove (zombie survival; the key is set in Options → Mouse) | Mouse 4 | shove (zombie survival) |

In zombie survival the shove bashes with any weapon: zombies in a short cone in front are
pushed back and staggered and lose their swing, and a teammate a hunter or a smoker holds is
knocked free. Spamming it tires you (the pips under the crosshair). It's on Mouse 4 and T (CS
1.6's spray key, unused here); pick another key in Options → Mouse. F stays the flashlight.

Useful console commands: `sensitivity 3`, `cl_showfps 0`, `net_graph 1`,
`vid_mode 800x600`, `vid_aspect 4:3`, `cl_crosshair_color "50 250 50"`, `bot_add_t`,
`bot_add_ct`, `bot_kick`, `bot_difficulty 0-3`, `mp_roundtime 3`, `mp_restartgame 1`,
`announcer 0`, `sv_cheats 1` + `impulse 101`. Type `help` for the full list.

## How it's made

| Area | Files | Notes |
| --- | --- | --- |
| Movement | `src/engine/pmove.js` | Port of Half-Life/CS `pm_shared.c`: ground/air acceleration (air strafing works), friction + edge friction, 18-unit step-up, CS duck timing and speed penalty, jump with the CS stamina/landing slowdown, footsteps only above 150 u/s. Runs at a fixed 100 Hz like `fps_max 100`. |
| Collision | `src/engine/collision.js` | Convex brushes with a BVH and swept-box traces (Quake 3 style), dynamic boxes for players. |
| Map | `src/map/dust2.js`, `areagen.js` | de_dust2's layout measured from its navigation mesh and radar overview (coordinates in GoldSrc units), built as brushes: floors per area, auto-generated building mass, hand-placed parapets, arches, doors, crates, windows, tunnel ceilings. |
| Lighting | `src/map/lightmap.js`, `tools/bake.mjs` | A tiny hlrad: 16-unit luxels, sun with shadows, sky light and one bounce, calibrated against reference screenshots. Pre-baked into `public/maps/` (rebaked automatically in the browser if the map changes). |
| Rendering | `src/engine/renderer.js`, `src/map/meshbuilder.js` | Gamma-space lighting, bilinear + nearest-mipmap filtering, no anisotropy, no AA, 90° horizontal FOV at 4:3 (Hor+ on widescreen), separate view-model pass. Optional 640×480 / 800×600 / 1024×768 modes and 4:3 pillarboxing. |
| Textures | `src/assets/textures.js`, `src/assets/tex/` | Procedural cs_dust-style textures, quantised to 256-colour palettes like WAD3. |
| Sky | `src/assets/sky.js` | Procedural "des" skybox rendered into a 256 px cube map. |
| Models | `src/assets/viewmodels.js`, `playermodels.js`, `worldweapons.js` | Low-poly first-person weapons with animations, the eight 1.6 player skins with hitboxes, world/dropped weapons, planted C4. |
| Sound | `src/assets/sounds.js`, `src/assets/snd/` | Every sound synthesised with Web Audio at load time; GoldSrc attenuation model. |
| Weapons | `src/game/weaponsys.js`, `combatrules.js` | CS 1.6 weapon logic ported from ReGameDLL_CS: spread/accuracy, recoil (KickBack), burst, silencers, zoom, penetration, armour, hitgroups, prices, economy. |
| Game | `src/game/` | Rounds, economy, C4, grenades, effects, bots (nav-mesh A*, CS-like aim and reaction), HUD state. |
| Zombie survival ("Dead of Dust") | `src/game/zombies.js`, `zdiff.js`, `zeconomy.js`, `zdowned.js`, `zfeedback.js`, `zorders.js`, `specials.js`, `bosses.js`, `fire.js`, `projectiles.js`, `explosives.js`; front end in `src/ui/front/`, `titlescene.js`, `ztips.js` | The title screen's Zombie Survival → setup: five difficulties (Casual to Nightmare, plus Sandbox: $16000, buy anything any time), up to 10 bot teammates, break length, squad scaling, hardcore. Start with a pistol and the difficulty's cash, earn by the kill and the wave, and shop in the breaks (mid-wave: ammo, armour, medkits at a markup; F1 readies up). At 0 HP you go down: crawl, shoot your pistol, and a teammate (bots too) holds E to pick you up before you bleed out; the run ends when the whole squad is down. The horde grows with the squad and keeps climbing (more, tougher, faster zombies; runners later), records are kept per map, difficulty and squad size, hit markers / streaks / a quiet kill counter confirm every hit, and radio orders (hold, follow, fall back) steer the bots. Zombies hunt along a flow field over the nav graph and claw whoever they reach; now and then a special infected turns up (sprinter packs, the bile-spewing boomer, the charging charger, the pouncing hunter, the tongue-dragging smoker). Extra arsenal: molotov, M2 flamethrower, RPG-7, M32 contact grenade launcher, M134 minigun, AA-12, Barrett M82, chainsaw, tesla gun, medkits (key 5; bots heal too), claymores and remote C4 that sticks where it lands (V sets them off). A melee shove (Mouse 4 or T) bashes with any weapon: it pushes back and staggers what's in front, cancels its swing and knocks a pinned teammate free, with L4D-style fatigue; bots shove too (`shove.js`). A boss every 5 waves (the Butcher, Spitter, Banshee, Inferno, Abomination), each with its own look and powers. |
| Perk draft (zombie survival) | `src/game/perks.js` (the modifier pipeline: `zmods.js`), `src/ui/perkdraft.js`, `src/ui/perkicons.js`, `src/assets/snd/perks.js` | Every break you draft 1 of 3 perk cards (4 on Casual, 2 on Nightmare) without leaving the game: hold 1-3 (a tap still switches weapons) or click while the pointer is free, hold the next key to reroll once (free the first time, then cash); the cards hide while the buy menu is up, and the wave picks at random if you don't. 28 perks (Deadeye, Scavenger, Pyromaniac, Field Medic, Bulk Order, Overclock, Demolitions, Rally Cry...), boon-and-curse gambles (Blood Pact, Glass Cannon, Hair Trigger, Juggernaut, Greed), rarer cards after every 5th wave, and tag pairs that unlock synergies (Pyro + Tesla = Plasma Arc, Napalm, Executioner, Guardian Angel, Black Market, Hit and Run). Bots draft for their guns and roles. Your perks sit in a strip above your health, everyone's in the scoreboard, and your build in the run report. |
| Weapon forge (zombie survival) | `src/game/zforge.js`, `attachments.js` (tiers), `src/assets/vm/attach.js` (tier paint), `src/assets/snd/forge.js` | Buy menu → Upgrades & Skins → Weapon Forge (breaks only): Tiers I-V on any gun or special weapon for damage, magazine and reload speed, with banded paint, an emblem with a pip per tier and, from Tier III, damascus / gilded / obsidian finishes. From Tier III load one round type: Incendiary (sets them alight), Shock (arcs to the zombies nearby), Cryo (chill, then freeze solid and shatter), Explosive (small blasts that hurt only zombies) or Vampiric (a little health back). Bots forge their main gun too. |
| Squad roles and orders (zombie survival) | `src/game/zsquad.js`, `zorders.js`, `src/assets/snd/squad.js` | Bots get roles (set them on the setup screen or leave them on Auto): a Gunner (M249, then the minigun later in the run), a Medic (revives first, heals sooner from farther), a Demo (shotguns, claymores where you hold, molotovs into packs, a pipe bomb to pull the horde off a downed teammate) and a Marksman (works up to the Barrett, specials and bosses first). Radio (Z) "Hold here" sets them in an arc facing the lanes the horde comes by; Follow, Regroup and Focus target (middle mouse or I: every gun on what you aim at). A squad panel on the right shows each bot's role, health and state (PINNED, DOWN 0:18, REVIVING...). |
| Bosses and elites (zombie survival) | `src/game/bosses.js`, `bossstage.js`, `zelites.js`, `relics.js`, `src/ui/bossbar.js`, `src/assets/trophy.js` | The five bosses come in a seeded shuffle (any of them can be first), announced by a rumble, dimmed lights, a roar from their direction and a title card. Shotguns, explosives, melee and weak-point hits fill a posture bar: break it and the boss kneels, taking double damage. Each boss gains a move at 66% and 33% health (the Butcher's meat hook, the Spitter's acid rain, the Banshee's phantom strike, the Inferno's meteors, the Abomination's earthshaker leap), with floor telegraphs. A kill gives back some health and armour and drops a trophy: pick 1 of 2 relics (rare perks, the boss's own first). Named elites (the Alpha Hunter, the Juggernaut) turn up on odd waves. |
| Loot, power-ups and airdrops (zombie survival) | `src/game/pickups.js`, `powerups.js`, `airdrop.js`, `drophud.js`, `src/assets/dropmodels.js`, `src/assets/snd/drops.js` | Kills drop cash, ammo and health vials (a budget a wave; bots fetch loot when it's safe). Rare power-ups: Max Ammo, Insta-Kill, Double Cash, Nuke and Fire Sale. Mid-wave a red flare marks an airdrop: a crate under a parachute, held E to open, with a heavy gun, a weapon kit, a forge core (your gun a tier up) or a supply draft (a perk card). |
| Zombie survival arsenal | `src/game/zarsenal.js`, `src/assets/vm/w_arsenal.js`, `src/assets/snd/arsenal.js` | Buy menu → Equipment: Melee & crossbow (machete, fire axe, katana - they replace the knife - and a silent hunting crossbow whose bolts go through one zombie and can be picked up again) and Special grenades (a pipe bomb that beeps and lures the horde in before it blows, a cryo grenade that freezes them solid: a blade or a blast shatters them, a bullet cracks the ice off). |
| Weapon upgrades | `src/game/attachments.js`, `src/assets/vm/attach.js` | Zombie survival buy menu → 9 Upgrades & Skins, for the gun in your hands: suppressor (quiet, no flash, the noise stops drawing zombies to you) or compensator, laser sight (beam and dot), red-dot sight (right-click aims down it), foregrip, extended magazine; and eight paint jobs (gold, carbon fiber, camos, crimson web, neon). The parts are placed on each view model by measuring the gun's own geometry. |
| Gore | `src/game/gore.js`, `statics.js`, `blood.js` | Explosions tear zombies into limbs and gibs; a headshot kill with a big gun pops the head. Bodies, gibs, blood, brass, bullet holes and scorch / burn marks stay for good: they are appended to static meshes per map area (culled per area, a low-poly index far away, soaked spots take no more decals), so a long game stays as fast as a short one. |
| UI | `src/ui/` | The 1.6 HUD, VGUI menus, buy menu, scoreboard, console. |

Development helpers: `node tools/bake.mjs` rebakes the lightmap,
`tools/preview/*.html` are per-module preview pages, `tools/shot.mjs` and
`tools/views.mjs` take headless screenshots.
