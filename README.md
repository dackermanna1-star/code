# BATTLEGROUNDS

A single-player, PUBG-style battle royale for the browser, built on Three.js, Rapier and TypeScript.

> **Development is paused.** To continue, read **[docs/RESUME.md](docs/RESUME.md)**. It covers status, resume steps and known issues.

```
npm install
npm run dev     # open http://localhost:5173  (?quick=1&debug=1 boots straight onto the island)
```

See `docs/ARCHITECTURE.md`, `docs/DESIGN.md` and `docs/ASSETS.md`.
