# "What happens if you get trapped inside an elevator for 3 days?" — 3D animated YouTube Short

Fully procedural Blender 4.5 LTS production: every model, material, rig, animation, camera move,
light cue, sound effect and caption is generated by the scripts in this folder.

**Final video:** `output/elevator_3_days_short.mp4` — 1080x1920 (9:16), 30 fps, ~47 s, H.264 + AAC.

## Pipeline

| Step | Script | What it does |
|---|---|---|
| 1 | `01_voiceover.py` | Neural TTS voiceover (Piper, `en_US-ryan-high`) from `story.py`; measures every line and estimates per-word timing → `build/timeline.json` |
| 2 | `02_build_scene.py` | Blender: builds the stylized character + technician, the elevator car (interior, doors, buttons, LED indicator, vent, cables, safety brakes), the shaft, the floor-7 hallway and the stairwell; animates 32 shots (poses, facial expressions, blinks, cameras, light cues, sparks, steam, dust, light beam) synced to the voiceover; binds cameras to markers → `build/elevator.blend` |
| 3 | `05_render.sh` | Renders all frames with EEVEE Next at 1080x1920 using parallel, resumable Blender instances → `build/frames/` |
| 4 | `03_audio.py` | Synthesizes all SFX (impacts, brake screech, alarm bell, phone beeps, heartbeat, gulps, elevator ding…) and a music bed, places them on story events, ducks under the VO → `build/mix.wav` |
| 5 | `04_post.py` | Bloom, vignette, grade, flash frames, punch-zooms, hook title, DAY cards and word-by-word captions; encodes the MP4 with audio |

Shared timing lives in `shots.py` (shot list + story events derived from the voiceover), so cuts,
character actions, SFX and captions all land on the same frames.

```bash
python3 01_voiceover.py build
blender -b --factory-startup -P 02_build_scene.py -- build/elevator.blend
./05_render.sh 2
python3 03_audio.py
python3 04_post.py build/frames output/elevator_3_days_short.mp4
```

Requirements: Blender 4.5 LTS, Python 3 with numpy + Pillow, `piper-tts` (+ the `en_US-ryan-high`
voice in `/opt/voices`), ffmpeg. Headless EEVEE needs an EGL driver (Mesa `libegl1` works).

## Story beats (shots)
Hook free-fall + shaft drop + slam → smashing buttons / alarm → phone: no signal, 3% → cutaway:
cables + emergency brakes → "the real danger is thirst" → DAY 1 (pacing, hunger, bathroom
corner gag) → DAY 2 (headache, dizziness, heat, vent) → DAY 3 (collapse, heartbeat, eye closing)
→ a crack of light → rescue crew pries the doors and hands over water → victory in the hallway
→ payoff: the elevator dings open… and he takes the stairs.
