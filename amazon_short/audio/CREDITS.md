# Audio credits — Amazon rainforest Short

All files below are 48 kHz WAV (16-bit) converted with ffmpeg from the originals in `sfx/originals/` and `music/originals/`.
Long field recordings were cut to an excerpt (noted in the description); one-shot SFX and music had leading silence trimmed (-60 dB).
Levels were NOT normalised; quiet recordings (e.g. macaws, panting, Mirador) need gain in the edit.

Licenses accepted: CC0, Public Domain Mark, CC BY, CC BY-SA only. **CC BY / CC BY-SA items require attribution in the video description** (see list at the end).
CC BY-SA: if you distribute a modified version of the *sound file itself* it must stay BY-SA; using it inside a video is fine with attribution.

Note on provenance: items credited to the *USC Cinema / Sunset Editorial SFX collection* (GOLD TAPE / SSE Library items) are marked CC0 by their Internet Archive uploader; the original library is a vintage film-SFX collection. They are used here per that stated license; prefer the field recordings where an alternative exists.

## QC notes (ffprobe + astats/volumedetect)

- All kept files verified 48 kHz, durations as listed. None near-silent; none hard-clipped.
- `mosquito_buzz_flying_around.wav` and `water_splashes_small_set.wav` touch 0 dBFS on a few isolated samples (flat factor 0, i.e. no flat-topping).
- `heartbeat_human_fast.wav` shows slight limiting in the source (flat factor ~4 at -2 dBFS); inaudible in context.
- Very quiet sources (RMS below -40 dBFS): `macaws_flock_panama`, `human_panting_*`, `human_breathing_tired`, `rain_light_on_leaves_drips`, `amb_day_rainforest_howlers_sunset_elmirador`; raise gain in the edit.
- Rejected after analysis: OGA 'Bird, cricket, frog and mosquito sounds' (synthetic, near full-scale), Chigorodó rain (walking/handling, uneven), Petén 'Rainforest by Night' (≈-50 dBFS RMS, noisy when boosted), Dorset 'Crunchy footsteps' (children's voices, 8 clipped samples), Pedro Aspahan mosquito (≈-48 dBFS), Puketi Stream (page carries a conflicting © notice).

## Not found / gaps

- Running footsteps on forest floor: no suitable free-licensed recording found (speed up / layer the walking-on-leaves files).
- Real Amazon outboard ('peke-peke') motor field recording: none found under an accepted license; boat engines are vintage SFX-library recordings.
- Wikimedia Commons downloads were blocked by persistent HTTP 429 rate-limiting on upload.wikimedia.org, so Commons candidates (e.g. 'Monos Congo - Howler Monkeys.WAV' CC BY-SA 3.0, 'Scarlet macaw 01.wav' CC BY-SA 4.0) were not downloaded.
