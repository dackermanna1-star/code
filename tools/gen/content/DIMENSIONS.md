# The 50 dimensions

Each line: `id` | dial code | name | terrain style | concept → key blocks/features → creatures (3 each, ★ = signature).
Specs live in `tools/gen/content/dims/<id>.py` (see `sporewood.py` for the reference implementation).
Every dimension needs 3–4 biomes, 5–10 custom blocks, 1–3 custom items, 3 creatures, a distinct sky/fog/ambience,
and at least one "wow" landmark feature. Danger in brackets (1 peaceful … 5 deadly).
