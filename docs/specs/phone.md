PACKAGE: phone   (order: 60; sets ctx.game.phone in init; also a texts library for everyone)

1. THE PHONE (ctx.game.phone): a period candybar phone (Nokia 1110 / 6300-like feel, fictional brand «NOVA» or similar) shown as a DOM/canvas overlay in the lower-right of the screen when the player presses Q (Game.js calls phone.toggle(), phone.handleInput(input, dt) while open, phone.update(dt) every frame, reads phone.open, calls phone.close()). Implement a small low-resolution colour or green-backlit LCD (draw on a canvas at e.g. 96×65 or 128×128 pixels scaled up with image-rendering: pixelated, inside a drawn phone body with keypad), with a pixel font that supports Cyrillic (draw your own tiny bitmap font for the needed glyphs, or use canvas text at small sizes with smoothing disabled). Screens: idle (operator name — parody of МТС/Билайн/МегаФон, e.g. «МегаЛинк», signal bars that weaken underground (game.zone indoor/metro), battery, clock from ctx.atmos.clock, date «14.01.2008» — the date never advances), menu (Сообщения, Контакты, Журнал, Игры, Фонарик, Настройки). Messages: inbox with a few pre-existing SMS (mum: «Ты где? Купи хлеба.», operator balance «Баланс: 12.40 р.», a friend's translit message, an old message from someone unknown); new SMS arrive VERY rarely (timed with game events — e.g. after 20+ minutes of walking, or after visiting the doppelgänger courtyard — subtle, ambiguous texts; never more than 3 per session) with 'phone_vibrate' + 'phone_sms' and a tiny envelope icon, no on-screen notification beyond a quiet caption via ui.say only the first time. Contacts: «Мама», «Серёга», «Работа», «???»; calling plays 'phone_ring_out' then 'phone_unavailable' («Абонент недоступен или находится вне зоны действия сети») — always. Журнал: missed calls list. Игры: a playable Snake (classic Nokia-style, arrow keys / WASD while the phone is open, high score in localStorage with try/catch). Фонарик: toggles ctx.game.toggleFlashlight() (also F key works globally). Settings: ringtone list (preview with synthesized monophonic ringtones via audio if available), contrast. Keys while open: arrows/WASD navigate, E/Enter select, Backspace/Esc back/close, Q close. Keypad presses play 'phone_key'. While the phone is open the player cannot walk (Game handles: it routes input to handleInput). The phone should look like a real object in hand (slight sway with time, backlight timeout dimming after 10 s). Respect ui.translations: show small English translations under the phone (outside the LCD), never inside the LCD.

Each item: {ru, en, style, kind}. Aim for 120+ items total, carefully written, non-cliché, everyday, some melancholic, some funny, no politics, no real brands.
